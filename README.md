# CaloTrack — Daily Calorie & Macro Tracker

A lightweight, responsive calorie and macronutrient tracking web application built entirely with vanilla web technologies.

## Features

- **Daily Calorie Budget**: Real-time calculation of consumed, goal, and remaining calories with visual status indicators.
- **Macronutrient Tracking**: Automatic aggregation of Protein, Carbs, and Fat (grams and kcal equivalents).
- **Meal Categorization**: Log and organize foods under Breakfast, Lunch, Dinner, and Snacks with per-meal subtotals.
- **Date Navigation**: Jump across dates, review history, or return to Today.
- **1-Click Quick Presets**: Rapidly add common foods with predefined macros.
- **Persistent Storage**: All entries and preferences are saved locally in the browser via `localStorage` (no backend required).
- **Zero Dependencies**: Pure HTML5, Vanilla CSS (no Tailwind, no CSS variables), and Vanilla JavaScript.

## Getting Started

Simply open `index.html` in any modern web browser. No build steps or server required.
